# Creator Inbox

Creator Inbox is a simple interface that helps Whop creators with communities get paid through text (message) requests.

## Problem

Many Whop creators do not leverage paid DMs at all, and those who do often end up with a messy process that is hard to organize and manage.

## Solution

Creator Inbox gives Whop creators and their community members one simple interface to submit paid message requests, track progress, manage requests & handle payments in one place.

Built for two core customer types:

- First-time Whop creators who want to monetize quickly.
- Established Whop creators with large communities who want to increase earnings with a structured request workflow.

## Tech Stack

- Next.js (App Router) + React + TypeScript
- Convex (database + backend mutations/queries)
- Tailwind CSS + shadcn/ui
- Whop SDK (identity, access, and payments)
- Inference API (AI-assisted request type generation)
- Vitest + convex-test (unit testing)
- pnpm (package manager)

## Quick Start

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.
